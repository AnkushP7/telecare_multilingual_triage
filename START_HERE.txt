QUICK START (3 STEPS):

Method 1: 1-Click Launch (Easiest)
----------------------------------
1. In Windows File Explorer, double-click:
      run_backend.bat
2. A console window will open and keep running. (Do not close it).
3. Your browser will automatically open:
      http://localhost:8000
   (If it doesn't open automatically, open your browser and go to http://localhost:8000).

Method 2: Command Line (PowerShell / Command Prompt)
---------------------------------------------------
1. Open PowerShell or Command Prompt.
2. Navigate to this folder:
      cd "C:\Users\hp\Downloads\telecare_prototype_triage_v2 (1)\telecare_prototype"
3. Run:
      python backend/server.py
4. Open http://localhost:8000 in your browser.
